## Component Usage

A `Table` displays tabular data in a structured and flexible way.

### Table

<STable client:only='vue' class='mt-4' />
<Code code={STableRaw} lang='vue' title='Default.vue' />

### Table Cell with Loading

Show content placeholder in certain cells.

<STableCellWithLoading client:only='vue' class='mt-4' />
<Code
	code={STableCellWithLoadingRaw}
	lang='vue'
	title='TableCellWithLoading.vue'
/>
