To contribute to Suteki Common Components, you need to follow the steps below:

```bash
$ git clone https://github.com/Suteki/@sutekitechid/sicoco-v3-shadcn.git
$ cd sicoco-v3-shadcn
$ npm install
$ git checkout feat/fix/[Feat name/component]
```

## Running the project locally

To run the project locally, you can use the following command:

<Steps>
	<ol>
		<li>Run the command `npm run dev` to run the project locally.</li>
		<li>
			The test project is already equipped with automatic tests, please add
			automatic tests for the components that have been created as well.
		</li>
		<li>Add the library documentation as a comment.</li>
	</ol>
</Steps>

## Pushing the changes to the repository

<Steps>
	<ol>
		<li>
			After adding / modifying the component, please create a pull request to
			the `main` branch.
		</li>
		<li>
			Wait until the automatic test is complete. In order for the branch to be
			merged into `main`, all test cases that have been created must be
			`PASSED`.
		</li>
		<li>
			After all testcases passed, wait for other team members to review and
			accept all changes that have been made.
		</li>
		<li>Merge to main.</li>
	</ol>
</Steps>

## Publishing the package

<Steps>
	<ol>
		<li>
			Login to npm with your GitHub account as mentioned in the [Running the
			project locally](#running-the-project-locally) section.
		</li>
		<li>
			Change the version of the package by running the command below:
			<Code
				code={`npm version [major|minor|patch]`}
				lang='bash'
				title='Change the version of the package'
			/>
		</li>
		<li>
			Run the command below to publish the package:
			<Code code={`npm publish`} lang='bash' title='Publish the package' />
		</li>
	</ol>
</Steps>
