Sicoco is a private package, you need to login to npm with your GitHub account to install it. To do this, you need to generate a personal access token from your GitHub account.

<Steps>
	<ol>
		<li>
			Go to Settings -> Developer Settings -> Personal access tokens (skip if
			you already have one).{' '}
		</li>
		<li>
			Run `npm login -registry=https://npm.pkg.github.com -scope=@sutekitechid`
			when you switch projects/repositories.
		</li>
		<li>
			Enter your username and password. Use the token you generated as the
			password.
		</li>
		<li>
			Import sicoco v3 next css file and icomoon css file in your nuxtjs / vuejs
			config

      <Code code={SicocoImportExample} lang='vue' title='nuxt.config.ts' />
    </li>
    <li>
      Add tailwind configurations
      <Code code={tailwindConfigExample} lang='javascript' title='tailwind.config.ts' />
      <Code code={tailwindcssConfigExample} lang='css' title='tailwindcss.css' />
    </li>

  </ol>

</Steps>
