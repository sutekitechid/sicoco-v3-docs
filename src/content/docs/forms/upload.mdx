An `Upload` component is a UI element that allows users to select and upload files from their device to a server or application. It is commonly used in forms or content management systems to handle file attachments, images, or documents.

## Component Usage

### Default

A default upload is a basic UI element that allows users to select and upload a file.

### Validation

The `validation` prop restricts the file types or conditions that can be selected for upload. Use it to ensure users only upload files that meet specific criteria, such as file type or size.
